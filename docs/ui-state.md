# v3 工作台界面状态契约

Figma 正式工作台、外设、流程和联网通信页面为布局参照；组件沿用现有 React、Dialog、Chart、Board 及苍渊·白垣 Token。首屏默认白垣，主题切换只改变根元素 data-theme，不创建第二套页面逻辑。

|对象/状态|展示与动作|
|---|---|
|未连接|连接入口；不显示虚构身份或示例采样|
|连接与身份验证中|SDK 公开连接过程尚未完成，不伪造传输已成功的细分进度|
|读取能力|握手身份已核验，等待完整 discovery 和一致快照|
|能力读取失败|保留已核验身份，允许只读重新获取，不申请控制|
|已连接|所有页面立即可操作；共享本连接创建的资源|
|页面离线或刷新|保持连接与输出，其他页面继续操作|
|通知有缺口/短暂恢复|保留已确认状态；合并查询，不禁用已可用按钮|
|状态待同步|保留最后快照并标记陈旧；不从旧配置推断实际输出|
|预检通过|仅当前校验通过，不代表预留；配置改变使该预检失效|
|opening/ready/closing/fault|设备真源；fault 仍占用，recover 只重试关闭|
|running|普通 a3 高层业务正在执行；仅确认结果后显示完成|
|submitted/accepted|高级批量本地入队和设备受理；显式作业保留真实编号|
|completed/failed/cancelled|按 SDK 直接响应或原始 job 终态更新；保留驱动原码|
|unknown|可能已经执行，无自动重试；同 boot 已知 job 可查询|
|result_expired/job_expired|结果内容过期与历史句柄淘汰分别说明|
|文件上传中/校验提交中|字节进度和最终 commit 分开；进入 commit 后不承诺可中止|
|流程暂停/运行完成|不代表输出清空，停止并确认清理后才移除|
|全局停止中|等待原始 stop job，失败保留清理/持久化错误与占用|

主导航为设备工作台、外设调试、离线流程、板上文件、联网通信、设备维护。资源类型、引脚、配置、动作和系统能力基于 discovery.available，不以 profile 名称套静态菜单。未知描述保留原文，不执行设备字符串。

常用外设提供中文字段、范围、布尔/枚举选择、预检与动作按钮；高级嵌套参数使用字段/列表编辑器，原始 JSON 作为只读详情。采样、网络状态、文件与任务使用可读结果，并保留完整结构化导出。

周期 ADC raw/mV 记录按小端有符号整数解码，负 mV 为未校准；连续 ADC type2 按通道/单元标签解码，RMT 按持续时钟计数与电平解码，I²S/PDM 保持原始格式。图表不伪造 0 V 或物理精度，缓冲最多 120 条。

宽屏沿用顶栏、轻导航、连续主任务与辅助区；窄屏导航换行、辅助区下移，流程画布在局部滚动，不撑宽整个页面。对话框使用原生 dialog，管理焦点返回与 Escape，动作按钮点击后直接执行，不弹浏览器二次确认，也不要求重复输入确认文字；维护接口所需的协议参数由提交入口补齐。

板图用独立于类别色块的图形表达实际模式与 GPIO 确认电平：空闲留白，高/低电平分别使用实心/空心，箭头随正反面始终相对板子表达方向；PWM、采集和未知使用各自符号。保护位置使用锁图标，不显示旧斜纹或星号。读数与资源实例及连接身份绑定，初始配置不能充当实际电平。右栏正常写入/读取不新增等待或成功说明，不改变按钮尺寸；保留读回值直到新确认结果或明确失效，异常只在主操作附近显示一处。

点击已有 GPIO 引脚直接进入模式与电平控制；保留“选择其他功能”返回功能目录。输入资源不伪造输出按钮，模式循环按钮在实验面板直接可见。配置改变后主动作使用“输出高电平/输出低电平/启用输入”等明确动作，避免含糊的“应用新配置”。LED/GPIO 常规替换、单资源关闭、释放与保存不要求二次弹窗确认，执行反馈仍以设备确认和读回为准。

正式工作台以 1366×720 为设计对照：标题与接线方案同一行，32px 工具栏、完整 360×480 板图、固定身份及诊断入口；配置区独立滚动。窄屏保留 288×388 板图与返回入口，不缩小 13px 引脚标签。常驻图例移入工具栏，图例以 643×158 原生对话框展示，窄屏换行适配；此信息面板不涉及操作确认。
