# 工作台设计同步核对

当前实现已同步 V5 紧凑板图、功能家族及 GPIO/PWM 简化配置。最新结果见下节；前面的 V4、LED 和设计阶段记录保留为历史核对依据。

## SDK a2 与逐引脚状态

2026-10-25，分支 `feat/sdk-a2-board-status`。既有 64 个直接实验画板和 18 个当前状态组件变体同步清理正常等待、最近读回和成功说明；进行中沿用确认电平及主按钮尺寸，只有异常保留主操作附近的说明。开漏说明随模式固定，不随高低电平增减。

板图直接在引脚名旁显示模式与 GPIO 读回的 0/1；未知用 ?，PWM/ADC 仅显示模式，完整角色通过说明查看。保留电气颜色、保护斜纹、D5 矢量、13px 引脚名、至少 12px 状态字和 24px 命中高度。标准480、紧凑388、窄屏288×388分别核对，两主题原生组件样例位于[引脚工作状态与共享观察](https://www.figma.com/design/AzGxH7vvqqpSfxBXUBRYbf/limivia?node-id=2334-49322)。窄屏右侧条目使用专用 4px 间距组件，避免模式标签换行。

浏览器使用真实前后端与 SDK a2 模拟设备，逐帧连续切换核验右栏位置、高度和主按钮尺寸；共享读取、实例变化和清理语义由后端行为测试验证。

## GPIO 直接实验与按需保存

2026-10-25，分支 `feat/direct-gpio-experiments`。产品评审确认基础 GPIO 不应强制先保存方案，原“预检通过但应用灰色”的入口由直接实验替代。现有区域 2311:37508 就地更新为 `V5 · GPIO 直接实验与按需保存`，包含 64 个两主题桌面及手机配置内容画板；GPIO10 功能选择入口指向直接实验。

入口：[白垣输出待启用](https://www.figma.com/design/AzGxH7vvqqpSfxBXUBRYbf/limivia?node-id=2319-44304)、[苍渊手机配置](https://www.figma.com/design/AzGxH7vvqqpSfxBXUBRYbf/limivia?node-id=2319-48551)。基础区显示模式和必要上下拉，首次电平与其他参数按需展开；主按钮明确“取得控制并输出高电平”，和执行/阻塞说明一起固定在配置区底部。未启用状态不展示空白反馈占位，数字输入、运行、观察、故障、断线、预检失败与占用均有独立状态示例。

“保存到接线方案”是次要折叠动作，名称与备注按需填写。首次执行原型为选模式→输出待启用→进行中→确认高电平，并展示输出切换、停止与可选保存；复杂参数组合、权限判断和方案版本处理由代码及浏览器测试验证。画板使用原生文字、组件、变量和矢量，无整页图片；手机画板聚焦配置内容，完整导航由应用截图验证。

公共输入仍为 2px、近白底色，循环按钮保留 6px 实体形态。已有 PWM、总线及历史 GPIO 设计记录保留，不将旧的必选保存/检查流程用于当前 GPIO10 入口。

首次创建中与已有输出切换中分别展示，创建结果未知时不提前显示目标电平、不自动重试。主操作栏位于配置滚动区之外，避免遮住模式按钮；手机操作行保留 44px 高度。最终结构核验：64 个画板、3792 个文字节点，字体均为 Noto Sans SC，无整页图片或缺失原型跳转目标。

## GPIO / PWM 简化配置与输入样式

后续按钮外观和 GPIO 运行状态调整见下节“实体按钮与 GPIO 当前状态”；本节保留首轮输入式循环控件的历史记录。

2026-10-25，分支 `feat/simple-gpio-pwm-controls`。采用 Impeccable 简化表单层级，并沿用苍渊·白垣锁定色值。在原文件新增 `V5 · 简化 GPIO 与 PWM`（2300:23792），包含两主题的桌面及手机配置内容，共 60 个画板。入口为 [GPIO 输入](https://www.figma.com/design/AzGxH7vvqqpSfxBXUBRYbf/limivia?node-id=2300-23793)、[苍渊 PWM](https://www.figma.com/design/AzGxH7vvqqpSfxBXUBRYbf/limivia?node-id=2300-33774)及 [手机 PWM 配置内容](https://www.figma.com/design/AzGxH7vvqqpSfxBXUBRYbf/limivia?node-id=2303-35320)。原首页 2076:6808 / 2079:9259 保留，当前 GPIO10 板图入口连接新配置流程。

- GPIO 模式、上下拉、初始电平采用一个按钮循环当前值；数字输入隐藏电平与驱动，开漏同时展示电平与上下拉。高级设置默认折叠，显式值计数包含 0 和 false；边沿监听启用时才展示消抖。
- PWM 占空比使用滑杆与精确输入，频率使用数字框；分辨率、反相、结束电平和呼吸周期按需展开。名称备注单独折叠，更换引脚有板图选择与取消状态。
- Figma 原型提供模式、上下拉、电平、边沿、折叠和示例滑杆值之间的跳转。原型是状态演示；任意参数组合、连续小数、模式往返保留值和保存重载由实际代码实现与测试。手机画板聚焦配置内容，不包含完整导航壳层。

公共组件新增输入控件集 2296:24226（循环/数字、桌面/触摸、默认/悬浮/焦点/禁用）、滑杆 2296:24325、高级循环 2297:24261 和折叠入口 2297:24286。`color/inputBackground` 在白垣引用 `color/surface`（#FCFBF8），苍渊引用原 `surfaceSubtle`；禁用引用 `bgSecondary`。`radius/input` 为项目输入适配值 2，原品牌 6/8px 圆角 Token 不变。既有输入组件同步使用新角色；普通操作按钮、导航和卡片保持原形状。

代码以 `SimpleConfig.tsx` 组织 GPIO/PWM 基础与高级参数，`parameters.ts` 统一枚举解析和有限数字范围。新建参数尊重能力边界；既有缺省、0、false 和小数不被自动重写。通用资源调试及后端设备模型没有改动。折叠箭头复用原始 `family-chevron.svg`，循环矢量在 Figma 与代码使用相同路径，没有新增外部图片资源。

最终结构核验：60 个画板、4158 个文字节点均使用 Noto Sans SC，无图片填充节点，无缺失原型跳转目标。桌面两主题及手机配置内容已截图对照；浏览器、单测和实机只读走查见 [验证记录](verification.md#2026-10-25gpio--pwm-简化配置与输入样式)。

## 业务与交互检查

- 导航支持来自本次 `discovery.operations/resources`，文件使用实际的 `storage.*` 能力。设计示例中禁用的入口不会被照抄成某个 profile 的固定限制。
- 配置草稿和侧栏选中均属于前端视图，不创建资源。点击当前主导航保留正在编辑的草稿；切换到另一资源仅改变当前选择，不重新创建资源。
- 资源列表来自当前连接代次的快照。更换连接或固件身份后旧选择失效；占用来源不等于当前页面取得了控制。
- 未创建资源、过期状态、未知结果和其他来源占用保持明确文字；不显示成已熄灭。LED 的开关、呼吸、读取、模式切换确认及权限仍使用原有业务链路。
- 侧栏中部独立滚动，顶部上下文与底部辅助入口保留；正文和首页能力表支持键盘滚动。650px 以下改为顶部导航网格；窄屏和 200% 放大检查无水平溢出。
- “引脚与占用”按新版放在外设等设备页面的辅助区，首页和流程页面可从“固件与能力”弹窗访问。主题切换保留在底部版本行；这是为保留原有操作补充的小型文本入口。
- 设计的固件、资源、波形与流程为示例。既有业务表单继续按设备能力生成，不将示例数据当作设备输出或物理测量。LED 标注保留“输出示意 · 非物理测量”。

## LED 最近确认值与全局文字稳定显示

进一步修正了普通 `stale` 同时驱动多个无关标签的问题：资源快照待同步不等于固件能力未识别，也不等于 LED 的历史确认值消失。侧栏可用性、能力摘要和协议验证文字已独立于普通快照刷新；连接保持“已连接”。“操作记录”入口只显示固定文字，进行中数量移至记录弹窗。

LED 主状态改为“设备最近确认输出”，执行期间保留最近读回的输出及示意。按钮立即禁用以防重复提交，但保留操作前文案。新的输出在命令完成、状态读回及快照同步后显示；进度、错误和持续超过 300ms 的待同步情况只在既有 40px 反馈区展示。没有确认值时保持未知，断线、未知结果、资源关闭或更换实例会使旧确认值失效；更换连接、启动标识和资源实例均有独立作用域。此记忆是前端展示投影，不是目标输出，也不放宽写入所需的控制权和新鲜快照条件。

### D5 首次入口与定位提示

GPIO13 绿色焊盘内部加入 16×14 的 LED 线性矢量，其他引脚不显示该符号。Figma 与代码使用相同路径；透明度按 1→0.65→1 轻微呼吸，每周期 2.4 秒，共三次后停止。它只提示 D5 位置，不宣称物理灯已点亮；应用在 `prefers-reduced-motion: reduce` 下完全关闭动画。
